# SkillBox 📦

> 基于 Git 原生能力驱动的 AI Agent 技能管理器，自带 WebUI 控制台。支持**多 Git 仓库与独立分支**管理、**全局默认与单 Skill 专属安装路径**、多选勾选挂载与一键自动增量更新。

---

## 🌟 核心特性

- 🌿 **支持配置多个 Git 仓库**：可同时纳管多个私有/公开仓库（内网 GitLab、GitHub、Gitea 等），每个仓库独立指定**分支（Branch）**与**子目录（Subdirectory）**。
- 📁 **灵活的双层安装路径架构**：
  - **全局默认安装目录**：统一设置所有未特殊指定的技能默认安装位置（如 `~/.agents/skills`）；
  - **单 Skill 专属自定义安装目录**：支持在界面上为任意具体 Skill 单独指定目标目录（例如特定项目的 `.opencode/skills`、`~/.cursor/skills` 等），留空自动回退继承全局默认路径。
- 🌐 **高颜值 WebUI 面板**：内置搜索、仓库源下拉筛选、全选/反选、卡片流及独立弹窗配置。
- 🔗 **符号链接/目录联结秒级挂载**：Windows 使用 NTFS 目录联结（Junction，无需管理员权限），类 Unix 系统使用软链接（Symlink），零磁盘冗余占用，仓库更新本地实时生效。
- 🔄 **细粒度与一键自动更新**：支持对单一仓库源单独更新，也支持点击「全部拉取/更新」一键完成所有仓库的最新代码同步。
- 💾 **配置持久化**：所有仓库源、分支与单技能路径覆盖均持久化保存在 `config.json` 中，重启即开即用。
- 🪶 **极简自包含**：纯 Python 标准库编写，无需复杂运行环境与构建工具。

## 🚀 快速上手

### 1. 启动控制台
* **Windows 双击**：直接运行根目录下的 `start.bat`。
* **命令行**：
  ```bash
  python app.py
  ```
启动后会自动在系统默认浏览器打开控制台：`http://127.0.0.1:7860`。

### 2. 使用步骤
1. **设置全局默认安装目录**：
   - 在左侧首个卡片中配置通用路径（例如 `C:\Users\YourName\.agents\skills`），点击保存。
2. **添加/管理 Git 仓库源**：
   - 点击「🌿 添加仓库」按钮；
   - 填写仓库名称（如“公司业务中台”）、Git 仓库地址、指定分支（如 `dev`）及 Skill 所在子目录（如 `skills`）；
   - 保存时系统将自动拉取该分支并解析所有 Skill。
3. **按需配置单 Skill 专属目录（可选）**：
   - 如果某个 Skill 只希望安装到特定项目下，点击卡片中的 **「修改」** 按钮，填入该项目的专属路径（如 `D:\workspace\my-project\.opencode\skills`）；
4. **勾选并应用同步**：
   - 勾选你需要启用的技能卡片，点击右上角 **「⚡ 应用同步」**；
   - 系统会自动在目标目录建立符号链接/目录联结；
5. **后续更新**：
   - 点击右上角 **「🔄 全部拉取/更新」** 或左侧单个仓库的 **「更新」**，即可将远程代码同步到本地挂载目录。
