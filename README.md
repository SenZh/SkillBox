# SkillBox 📦

> 基于 Git 原生能力驱动的 AI Agent 技能管理器，自带 WebUI 配置面板，支持自定义私有 Git 仓库、指定分支、指定子目录、多选勾选与一键增量更新。

---

## 核心特性

- 🌐 **可视化 WebUI 面板**：基于浏览器的高颜值轻量控制台，内置搜索、卡片流与复选框（Checkbox）。
- 🌿 **原生多分支支持**：解决同类产品无法指定分支的痛点，支持任意自定义分支（如 `dev`、`feature/xxx`、`v1.0`），切换分支自动重新检出。
- 📁 **支持指定子目录**：适配 Monorepo，精准加载 Git 仓库内指定目录（如 `skills/`）下的技能包。
- 🔗 **符号链接/目录联结秒级挂载**：Windows 使用 NTFS 目录联结（Junction，无需管理员权限），类 Unix 系统使用软链接（Symlink），零磁盘冗余占用，修改即生效。
- 🔄 **自动拉取与增量更新**：点击「拉取/更新分支」自动执行 `git pull`，本地已挂载的技能秒级获得最新代码。
- 💾 **配置持久化**：本地保存仓库与分支配置到 `config.json`，下次启动即开即用。
- 🪶 **零重型依赖**：纯 Python 标准库编写，无需安装第三方大型 Web 框架。

## 快速上手

### 1. 启动服务
* **Windows**：双击运行项目根目录下的 `start.bat`。
* **命令行**：
  ```bash
  python app.py
  ```
启动后程序会自动在默认浏览器打开控制台：`http://127.0.0.1:7860`。

### 2. 配置与使用
1. **左侧表单配置**：
   - **Git 仓库地址**：输入你的公开或私有 Git 仓库（支持 HTTP、HTTPS 或 SSH）。
   - **Git 分支**：填写需要使用的分支名称（如 `dev` 或 `feature/v2`）。
   - **子目录**：填写包含 Skills 的相对目录（如 `skills` 或 `.`）。
   - **目标安装目录**：填写你期望 Agent 读取的目录（如 `~/.agents/skills` 或项目内的 `.opencode/skills`）。
2. **拉取与扫描**：
   - 点击右上角 **「拉取/更新分支」**，系统将在本地安全缓存区拉取该分支并扫描提取每个 Skill 的 `SKILL.md` 简介。
3. **勾选与同步**：
   - 在卡片流中**勾选**需要启用的技能；
   - 点击右上角 **「⚡ 应用同步」**，系统将自动建立符号链接挂载到目标目录。
4. **后续更新**：
   - 当远程分支有新代码推送时，在界面点击 **「拉取/更新分支」** 即可一键更新。
